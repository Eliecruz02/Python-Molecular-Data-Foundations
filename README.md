# Python Foundations for Molecular Data

## Overview

This project demonstrates foundational Python skills for organizing, validating, filtering, comparing, and visualizing simplified molecular data.

A small amino-acid property dataset was represented using Python lists and dictionaries. A synthetic protein segment was then annotated with broad chemical properties and analyzed using conditional filters, reusable functions, set operations, pandas tables, validation checks, and Matplotlib figures.

## Skills demonstrated

- Python lists, dictionaries, tuples, and sets
- Loops and conditional statements
- Functions, parameters, and return values
- List and dictionary comprehensions
- Dataset validation using assertions
- pandas DataFrames and CSV output
- Set intersections, differences, and unions
- Colorblind-friendly Matplotlib visualization
- Reproducible Jupyter Notebook organization

## Project workflow

1. Created a simplified amino-acid property dataset.
2. Validated required fields, data types, code lengths, and unique identifiers.
3. Created a synthetic numbered protein segment.
4. Connected residue identities to amino-acid properties using a lookup dictionary.
5. Filtered residues by category, charge, aromaticity, and sequence range.
6. Compared two synthetic residue groups using set operations.
7. Created residue-level and summary tables.
8. Generated colorblind-friendly summary figures.
9. Validated all generated output files.

## Important note

The amino-acid and residue datasets are educational examples. They were designed to demonstrate Python programming concepts and do not represent results from a real protein or biological experiment.
